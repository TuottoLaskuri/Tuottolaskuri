Varallisuuden kehitys

Mikä on korkoa korolle -ilmiö?

Korkoa korolle -ilmiö (engl. compound interest) tarkoittaa prosessia, jossa sijoituksen tuottama korko tai arvonnousu alkaa tuottaa uutta tuottoa alkuperäisen pääoman lisäksi. Albert Einsteinin tiettävästi kutsuma "maailman kahdeksas ihme" on pitkäjänteisen säästäjän tehokkain työkalu varallisuuden kasvattamiseen.

Miten korkoa korolle lasketaan?

Peruskaava korolle on seuraava:

A = P(1 + r/n)^(nt)

  • A = Tuleva varallisuus myöhemmin
  • P = Alkuperäinen sijoitettu pääoma
  • r = Vuotuinen korkokanta/tuotto desimaalina
  • n = Koron maksujaksojen määrä vuodessa
  • t = Aika vuosina

Miksi kuukausisäästäminen kannattaa?

Säännöllinen kuukausisäästäminen tasoittaa osakemarkkinoiden heilahteluita (ajallinen hajauttaminen). Kun markkinat laskevat, samalla kuukausisummalla saa ostettua enemmän rahasto-osuuksia tai osakkeita, mikä vauhdittaa tuottoa markkinoiden myöhemmin elpyessä.
